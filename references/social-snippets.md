# Social Media Snippets

This document provides social media snippets for sharing generated profiles.

## README Integration

Add these to your README.md:

```markdown
## GitHub Stats

![Stats](stats.svg)

## Contribution Snake

![Contribution Snake](snake.svg)

## Certificate

![Certificate](certificate.svg)
```
